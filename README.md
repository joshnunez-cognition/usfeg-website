# USFEG Website

Landing page built with Vite, React, TypeScript, and Tailwind CSS.

## Development

```sh
npm install
npm run dev      # start dev server
npm run build    # typecheck + production build to dist/
npm run lint     # oxlint
npm run preview  # serve the production build
```

## Structure

- `src/App.tsx` — landing page sections (header, hero, features, CTA, footer)
- `src/index.css` — Tailwind entry point and global styles
